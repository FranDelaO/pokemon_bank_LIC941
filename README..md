# Pokémon Bank – Cajero Automático (ATM)

Interfaz web que simula un cajero automático para **Pokémon Bank**.
Fase 1 · Lenguajes Interpretados en el Cliente (LIC941) 

## Pantallas
- **Login** (`index.html`): ingreso con PIN de 4 dígitos.
- **Acciones** (`acciones.html`): datos del titular, depositar, retirar, consultar saldo, pagar servicios y salir.
- **Historial** (`historial.html`): transacciones por tipo y monto.
- **Gráfico** (`grafico.html`): análisis de los tipos de transacciones.
